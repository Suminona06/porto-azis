# Design: About Page 1:1 Reference Parity & Shared Motion Primitives

## Context

See `proposal.md` for motivation and scope. Technically, this repository is an **Astro v7** SSR application (`astro: ^7.4.12`) styled with **Tailwind CSS v4** (`@tailwindcss/vite`) and animated exclusively with **GSAP (`gsap: ^3.15.1`) + `ScrollTrigger`**—there is no React or `framer-motion` dependency. Currently:
- `src/components/portfolio/HeroSection.astro` and `src/lib/motion/landing-motion.ts` inline the Homepage Hero character decode (`createAlphabetDecodeTween` / `createCipherDecodeTween`) and solid inverse `scaleX` block mask wipe directly inside Homepage-specific selectors (`[data-hero-decode]`, `[data-hero-role-mask]`).
- `src/pages/about.astro` renders a static boxed hero and a 2-paragraph static `A JOURNEY OF PROGRESSION` section backed by Supabase `about_sections` (`src/lib/content/placeholder.ts` and `src/lib/content/types.ts`).
- `src/components/portfolio/PreloaderCurtain.astro` coordinates public-page entrance timing via `window.__azisPreloaderDone` and the `azis:preloader-complete` custom event.

## Goals / Non-Goals

**Goals:**
- Extract reusable Astro motion primitives under `src/components/motion/` (`CipherText.astro`, `BlockMaskReveal.astro`, `ImageCurtainReveal.astro`) powered by shared GSAP lifecycle helpers in `src/lib/motion/`, so `/` and `/about` share one animation implementation.
- Overhaul `/about` Hero and "A Journey of Progression" to 1:1 layout, density, and motion parity with the reference video while keeping Light/Dark CSS theme tokens, `EN`/`ID` CMS fields, and `prefers-reduced-motion` support intact.
- Keep `gsap` + `ScrollTrigger` as the sole motion runtime with `gsap.context()` cleanup and zero layout shift.

**Non-Goals:**
- Installing React, `@astrojs/react`, or `framer-motion`.
- Redesigning `/about` downstream sections (`SkillsAccordion`, `ActivitiesList`, `Personal Interest`, `ContactBanner`) beyond preserving them cleanly below the Journey section's `1px` bottom hairline divider.
- Changing database schema columns in Supabase (`about_sections` already stores `headline_en`, `headline_id`, `profile_image_url`, `journey_en`, `journey_id`).

## Decisions

### 1. Astro + GSAP Motion Primitives (`src/components/motion/*.astro` + `src/lib/motion/primitives.ts`)
- **Decision:** Implement `<CipherText />`, `<BlockMaskReveal />`, and `<ImageCurtainReveal />` as Astro components in `src/components/motion/` that emit semantic, layout-locked DOM markup with `data-motion-*` attributes, orchestrated by a shared GSAP controller (`src/lib/motion/primitives.ts`) plus `src/lib/motion/text-scramble.ts` and `src/lib/motion/easing.ts`.
  - **`CipherText.astro`:** Props: `text`, `as` (`'span' | 'h1' | 'p'`), `durationMs` (default `800`), `charset` (`'alnum' | 'alphabet'`, default `'alnum'`), `delaySec` (default `0`), `trigger` (`'entrance' | 'manual'`), `class`. Renders an `sr-only` exact text span for screen readers and `aria-hidden="true"` word boxes containing an `invisible` spacer and an `absolute inset-y-0 left-0` animated layer so width/line-wrapping never jitters (`0px` CLS).
  - **`BlockMaskReveal.astro`:** Props: `durationMs` (default `700`), `delaySec` (default `0`), `trigger` (`'entrance' | 'manual'`), `class`, `maskClass`. Wraps `<slot />` inside a `relative inline-block overflow-hidden align-top` container with `[data-block-mask-content]` and an `aria-hidden="true"` overlay `[data-block-mask-box]` (`bg-[var(--bg-inverse)]`, `#FFFFFF` in Dark mode). Splits the `700ms` duration into two equal `350ms` halves using `editorialEase` (`[0.77, 0, 0.175, 1]`): `scaleX: 0 -> 1` from `transformOrigin: '0% 50%'`, flipping content `opacity: 0 -> 1` and `transformOrigin: '100% 50%'` at midpoint, then retracting `scaleX: 1 -> 0`.
  - **`ImageCurtainReveal.astro`:** Props: `durationMs` (default `700`), `delaySec` (default `0`), `trigger` (`'entrance' | 'manual'`), `class`. Wraps `<slot />` inside a sharp rectangular (`rounded-none overflow-hidden`) frame `[data-image-curtain]` starting at `clip-path: inset(100% 0 0 0)` and animating to `clip-path: inset(0% 0 0 0)` over `durationMs` (`700ms`) with `editorialEase`.
- **Alternatives Considered:** Adding `@astrojs/react` + `framer-motion` (`useScroll`/`useTransform`). Rejected because it duplicates the animation runtime, inflates bundle weight, and breaks consistency with `landing-motion.ts` and `PreloaderCurtain.astro` which already use `gsap` + `ScrollTrigger`.
- **Homepage Refactor (`HeroSection.astro` + `landing-motion.ts`):** `HeroSection.astro` uses `<CipherText />` (with `charset="alphabet"`, `durationMs={1100}`, `trigger="manual"`) and `<BlockMaskReveal />` (`trigger="manual"`) so `landing-motion.ts` composes their shared timeline builders (`createCipherTextTween`, `createBlockMaskTween`) inside its sequenced 3-part Hero timeline (`t = 0s`, `t = 0.2s`, `t = 0.4s`), eliminating duplicate scramble/mask DOM & tween code.

### 2. About Hero 2-Line Headline & Metadata Resolution
- **Decision:** Keep the About Hero strictly to the 3-element layout (`min-h-[100svh]`, `flex flex-col justify-between`, `pt-32 pb-6 sm:pt-40 lg:pt-44 lg:pb-8` so the metadata row sits cleanly ~20% down from the top edge beneath `Navbar.astro`, matching the reference proportions):
  1. **Top Metadata Baseline Row:** `Copy.basedIn` (`BASED IN INDONESIA` / `BERBASIS DI INDONESIA`) on the left and `Copy.aboutTagEngineer` (`ENGINEER`) on the right, styled `font-mono-tech text-[11px] tracking-[0.2em] uppercase text-[var(--about-meta-ink)]` (`#666666` in Dark mode, WCAG-legible `#52525b` in Light mode).
  2. **Staggered 2-Line Display Headline Lockup:**
     - Derive `line1` and `line2` from `pickLocale(sections.headline_en, sections.headline_id, locale)` (normalizing literal `\n` escapes): if the CMS string contains a newline (`\n`) or pipe (`|`), split into `[line1, line2]`; otherwise fall back cleanly to `line1 = profile.display_name` (`AZIS MUHAMAD FADLI`) and `line2 = pickLocale(profile.role_en, profile.role_id, locale)`. Seed concise 2-line strings in `placeholder.ts` and `0002_seed_placeholder.sql` (e.g., `"AZIS MUHAMAD FADLI\nCLOUD & DEVOPS ENGINEER"`) so `AboutManager.astro` continues editing `headline_en` / `headline_id` with zero schema migration while guaranteeing the headline never overflows into the bottom-right portrait.
     - `line1` renders in `<CipherText as="span" durationMs={800} ... />` inside `<h1>` (`font-display uppercase text-[var(--text-primary)] tracking-tight leading-[1.08] text-[clamp(1.75rem,3.4vw,3.1rem)]`).
     - `line2` renders indented (`ml-[6%] md:ml-[7.5%] mt-1.5 sm:mt-2`) in `<BlockMaskReveal durationMs={700} ... />` (`font-sans-ui font-bold uppercase text-[var(--text-primary)] tracking-tight leading-[1.1] text-[clamp(1.45rem,2.9vw,2.65rem)]`).
  3. **Bottom-Right Monochrome Portrait:** Wrapped in `<ImageCurtainReveal durationMs={700} class="aspect-[3/4] w-[210px] sm:w-[240px] lg:w-[280px] rounded-none" />` with `grayscale contrast-105` on the `<img>` (`object-cover w-full h-full rounded-none`). Because the Hero container uses `flex-col justify-between gap-10`, the headline group (`self-start`) and portrait frame (`mt-auto flex justify-end`) occupy distinct vertical bands on mobile (`375px`) and desktop (`1440px`), guaranteeing zero overlap.
- **Preloader Synchronization:** `initAboutMotion()` waits for `window.__azisPreloaderDone` or `azis:preloader-complete` (matching `landing-motion.ts`) and triggers `<CipherText />`, `<BlockMaskReveal />`, and `<ImageCurtainReveal />` concurrently at `t = 0`.

### 3. Sticky "A Journey of Progression" Split & ScrollTrigger Word Illumination
- **Decision:** Render Section 2 with `border-b border-[var(--about-divider)] bg-[var(--bg-primary)] py-24 lg:py-36` (`--about-divider`: `#262626` in Dark mode, `var(--border-light)` in Light mode) and `grid grid-cols-1 lg:grid-cols-12 gap-y-10 lg:gap-x-8`:
  - **Left Column (`lg:col-span-5`):** `<h2 class="m-0 font-display uppercase text-[var(--text-primary)] text-2xl sm:text-[1.75rem] xl:text-[2rem] leading-[1.15] tracking-tight lg:sticky lg:top-32 self-start">` rendering `{copy.aboutProgressionHeading}` (`A JOURNEY OF PROGRESSION` on a single horizontal desktop line). Sticky is scoped strictly to `lg:` (`>= 1024px`) so mobile/tablet (`< 1024px`) flows naturally. Note: `overflow-x: clip` on `body`/`html` (already set in `src/styles/global.css`) preserves `position: sticky` without breaking sticky ancestry.
  - **Right Column (`lg:col-start-8 lg:col-span-5`):** `<div class="max-w-[52ch] space-y-6 font-sans-ui text-[14px] md:text-[15px] leading-[1.68] lg:col-span-5 lg:col-start-8" data-journey-journal>` creating the wide central whitespace and compact right-aligned reading column matching the reference screenshot, normalizing literal `\\n` sequences in `splitJourneyParagraphs` before rendering paragraphs. Each word is wrapped in `<span data-journey-word class="inline">` separated by normal spaces so line wrapping stays natural.
  - **Scroll-Scrubbed Illumination:** `about-motion.ts` registers a GSAP `ScrollTrigger` (`trigger: journalEl`, `start: 'top 80%'`, `end: 'bottom 45%'`, `scrub: true`, `invalidateOnRefresh: true`). Initial word state in Dark mode: `color: #333333` / `opacity: 0.25` (theme-adapted in Light mode via `--journey-word-dim` so unrevealed words appear clearly dimmed on `#ffffff` without disappearing), transitioning sequentially to `color: var(--text-primary); opacity: 1` word-by-word as `self.progress` advances, and reversing smoothly on scroll-up (`onUpdate`, `onLeave`, `onLeaveBack`).
- **Why not reuse `StatementReveal.astro`'s binary `data-revealed` attribute?** `StatementReveal.astro` swaps a CSS class (`--text-muted` -> `--text-primary` over `140ms`). For the 3-paragraph journal, scrubbing word color/opacity smoothly via GSAP or CSS custom property / per-word progress interpolation creates an even smoother line-by-line/word-by-word illumination matching the reference video (`#333333` / `0.25` -> `#FFFFFF` / `1`).

### 4. Reduced Motion (`prefers-reduced-motion: reduce`)
- **Decision:** Both CSS (`@media (prefers-reduced-motion: reduce)` in `src/styles/global.css`) and JS (`prefersReducedMotion()` + `MediaQueryList` `'change'` listener in `primitives.ts` and `about-motion.ts`) enforce instant static full-contrast states:
  - CSS fallback ensures `[data-block-mask-box]` is hidden, `[data-image-curtain]` uses `clip-path: inset(0% 0 0 0)`, and `[data-journey-word]` renders `color: var(--text-primary) !important; opacity: 1 !important;` even before JS hydrates.
  - JS teardown/fallback restores original unscrambled text on `<CipherText />`, kills any running GSAP timelines/ScrollTriggers, and locks final properties cleanly.

## Risks / Trade-offs

- **Single-line CMS `headline_en` override:** If a CMS user later saves a long single-line sentence in `headline_en` without a newline, squeezing it into a giant 2-line display lockup could wrap onto 4+ lines and push down the Hero. → **Mitigation:** Support explicit `\n` or `|` splitting in `headline_en`/`headline_id`, seed a crisp 2-line headline (`AZIS MUHAMAD FADLI\nCLOUD & DEVOPS ENGINEER`), and fallback gracefully to `display_name` + short role tag or a clean midpoint word split with clamped display typography (`clamp(...)`) and `min-h-[100svh]` flex-column spacing so headline and portrait still never overlap.
- **Sticky heading ancestor `overflow` trap:** Any `overflow: hidden` or `overflow-x: hidden` on an ancestor of `.lg:sticky` breaks CSS sticky behavior. → **Mitigation:** Ensure `<main>` and Section 2's wrapper avoid `overflow: hidden` / `overflow-x: hidden` (relying on `body`'s existing `overflow-x: clip`), and verify sticky pinning in headless Chromium.
- **Light-mode contrast for `#666666` and `#333333`:** Reference dark-mode colors (`#666666` metadata, `#262626` divider, `#333333` dimmed words) look authentic on `#000000` Dark mode, while Light mode (`#ffffff`) needs inverse/theme-adaptive values (`--text-muted: #52525b` for metadata, `rgba(0,0,0,0.12)` for divider, `#a1a1aa` / `opacity: 0.25` dimmed -> `#000000` / `opacity: 1` illuminated). → **Mitigation:** Define semantic CSS variables (`--about-meta-ink`, `--about-divider`, `--journey-word-dim`) with Dark values matching the exact reference hexes (`#666666`, `#262626`, `#333333`) and Light values matching `design-system-theming`.
