# Proposal: Monochrome Editorial Motion System for Homepage

## Why

The homepage (`src/pages/index.astro`) currently relies on static initial rendering and minimal inline scroll listeners (`StatementReveal.astro`), lacking the choreographed editorial entrance, tactile monospace micro-interactions, and layered sticky scroll depth observed in the reference landing page. Introducing a unified GSAP-powered motion system brings cohesive visual rhythm to Azis Muhamad Fadli's portfolio while preserving its existing bilingual (`EN / ID`) Supabase CMS data, Light-default / Dark-toggle theming, and WCAG AA accessibility standards.

## What Changes

- **Motion Runtime Standardization (`gsap`):** Add `gsap` (with `ScrollTrigger`) as the sole client-side animation dependency for this Astro v7 codebase (no React or `framer-motion` installed), coordinated through a clean client controller and `gsap.context()` lifecycle cleanup.
- **Every-Load Multilingual Preloader & Curtain Wipe (All Public Pages):** Add a full-viewport preloader on every initial load, route navigation, and reload across all public website pages (`/`, `/about`, `/work`, `/blog`, `/blog/[slug]`), excluding CMS admin routes (`/admin`, `/admin/login`) and bypassing immediately when `prefers-reduced-motion: reduce` is active, cycling uppercase serif labels (`"LOADING"` -> `"MEMUAT"` -> `"로딩 중"`), paired with a `0%`–`100%` monospace counter, bottom-edge `3px` horizontal progress bar (`scaleX: 0 -> 1`), and an unbroken `600ms` upward vertical curtain wipe (`cubic-bezier(0.77, 0, 0.175, 1)`).
- **Synchronized 3-Part Hero Entrance Choreography & Layout Parity (`HeroSection.astro`):** Render a full-viewport borderless canvas (`#000000` in Dark mode, theme-adaptive `--bg-primary` in Light mode) with top/mid-left Line 1 full name (`AZIS MUHAMAD FADLI` in large uppercase `Playfair Display` `font-normal`) and indented Line 2 role (`pl-6 sm:pl-12` in large uppercase bold `Plus Jakarta Sans`), bottom-right justified uppercase geometric Sans-Serif intro paragraph (`max-w-[440px] sm:max-w-[480px] ml-auto text-justify text-[#8A8A8A]` in Dark mode), and a borderless 3-slot bottom meta bar (bottom-left `profile.location`, bottom-center looping `1px × 24px` vertical scroll indicator line, bottom-right live `hh:mm A (GMT +7)` clock). Immediately after curtain exit (or on mount), run the sequenced 3-part entrance: `~1.0s` left-to-right uppercase alphabet (`A-Z`) decode scramble on Line 1 (`~35ms`/tick), `~0.85s` solid inverse block wipe (`0.2s` offset: `0.4s` expand `scaleX: 0 -> 1` from `origin-left` + `0.45s` retract `scaleX: 1 -> 0` from `origin-right` with `cubic-bezier(0.77, 0, 0.175, 1)`) on Line 2, and `~1.2s` seeded-random word-by-word fade-in (`0.4s` offset, `0-900ms` deterministic randomized per-word delays, `0.45s` `easeOut`) on the justified intro paragraph.
- **Selected Work 1:1 Full-Row Curtain Sweep, `mix-blend-difference` Inversion & Snappy Symbol Scramble (`SelectedWorkList.astro`):** Refactor Selected Work to match `ammar.sang.ceo` 1:1: a mixed-weight uppercase Serif header (`<span class="font-normal">SELECTED</span> <span class="font-bold">WORK</span>`) paired with right-aligned monospace year-span metadata (`(PROJECTS / '24-'25)`), zero-dead-zone (`gap-0`) rows inside `--work-surface` (`#0B0B0B` Dark / `#FAFAFA` Light) with `1px` dividers (`white/[0.08]` / `black/[0.08]`), an isolated full-row GSAP-animated `.work-layer` (`z-10`) carrying the inverted full-row curtain (`--work-curtain-bg`: `#000000` Light / `#FFFFFF` Dark) plus the flushed-right edge-to-edge thumbnail (`w-[220px] lg:w-[270px] h-[calc(100%-16px)] my-2 mr-2 overflow-hidden relative shrink-0`, `w-full h-full object-cover`, zero `opacity` fade), paired with a `z-20` `mix-blend-difference` text layer (`01` `w-12 shrink-0 tabular-nums` index with hover underline, single-line uppercase Sans-Serif title, `whitespace-nowrap` monospace tech stack) that inverts pixel-by-pixel along the sweeping `clip-path` curtain edge (`0.55s power3.out` enter, `0.45s power3.inOut` leave, smooth mid-flight reversal), and snappy `~420ms` (`40ms` tick) full-string pure ASCII punctuation/symbol scramble (`!@#$%^&*()_+-=[]{}|;:',.<>?/~`) across all 3 text columns on hover/focus that snaps back simultaneously on completion and resets instantaneously on `mouseleave`/`blur`.
- **Monospace Micro-Interactions, Live Clock & Header Polish:** Add a `350ms` trailing-character scramble on hover/focus/tap for the hero location label (`profile.location`), a real-time `hh:mm A (GMT +7)` Asia/Jakarta clock in the hero footer, and refine `Navbar.astro` fixed translucent backdrop (`bg-[var(--bg-primary)]/80 backdrop-blur-sm`) with sharp rectangular (`rounded-none`) high-contrast inversion on the `BLOG` action button while preserving `DESIGN.md` `33554400px` pill radius on primary external contact CTAs.
- **Borderless Header, Hero & Footer Visual Parity:** Remove all horizontal divider borders (`border-b`, `border-t`) and vertical separator bars (`w-px` dividers in `LocaleToggle.astro` and between `location` and the live `GMT +7` clock in `HeroSection.astro`), plus outer box borders on `LocaleToggle.astro` (`EN / ID` clean slash toggle) and `ThemeToggle.astro`, creating a seamless borderless transition across Header, Hero, and Footer in Dark (`#000000`) and Light (`#ffffff`) modes.
- **Centered Uniform Circle & Sans-Serif Quote Parity (`QuoteTechCircle.astro`):** Fix the broken side-by-side flex circle layout so a large responsive square circle (`min-h-screen` viewport section, uniform `2px` solid `var(--border-strong)` stroke, no partial scroll progress ring) centers horizontally and vertically with the uppercase geometric Sans-Serif (`Plus Jakarta Sans`, `font-medium`, `tracking-wide`, `leading-snug`) quote placed dead-center inside the circle.
- **Official 1:1 Brand SVGs for `MOST FAVORITE TECH` (`QuoteTechCircle.astro`):** Install `simple-icons` (plus verified authentic AWS mark when absent from `simple-icons`) and replace approximate outline glyphs (`LINUX`, `DOCKER`, `KUBERNETES`, `TERRAFORM`, `AWS`, and additional slugs) with 1:1 official brand silhouettes rendered in uniform dimensions, `#737373` monochrome default state, and crisp brand-accent/high-contrast hover and focus highlights inside square cards.
- **Footer Layout, Typography & Scale Parity (`Footer.astro` + `BaseLayout.astro`):** Refactor `Footer.astro` to match the `ammaricano` reference layout: remove all top/bottom divider borders, remove the `CMS` (`/admin`) link and `BASED IN INDONESIA` footer block, render the two-line top-left monospace block (`© 2026 — AZIS MUHAMAD FADLI` per explicit owner override of `antislop` R-02, plus live `hh:mm A (GMT +7)` clock), load `Playfair Display` `700` weight in `BaseLayout.astro` for a bold lowercase `azis` wordmark spanning ~85-90% of container width, and place horizontal uppercase monospace social links (`LINKEDIN`, `GITHUB`, `INSTAGRAM`, `THREADS`) at bottom-right.
- **Sticky Hero Overlap & Scroll-Scrubbed Statement Illumination:** Layer the Hero as a sticky base (`position: sticky; top: 0; z-index: 0`) under an opaque, `z-10` `StatementReveal.astro` curtain with a `1px solid var(--border-light)` top hairline border, and upgrade statement illumination to GSAP `ScrollTrigger` bidirectional scrubbing between WCAG AA `--text-muted` and `--text-primary`.
- **Contact Banner Typography, Crisp SVG Arrow & Rightward Pill Hover (`ContactBanner.astro`):** Style the homepage/contact banner headline with mixed typography—leading phrase (`LET'S HAVE`) in `Playfair Display` italic (`font-display italic font-normal`, loading `1,400` in `BaseLayout.astro`) and trailing phrase (`A CHAT`) in `Plus Jakarta Sans` bold (`font-sans-ui font-bold`)—replace the tiny `&rarr;` text glyph inside `.button-primary` (`GET IN TOUCH` / `CONTACT ME`) with a crisp, proportional inline `<svg>` arrow icon, and animate `.button-primary` on hover/focus to expand smoothly rightward toward the arrow direction without shifting surrounding layout.
- **Reduced-Motion Accessibility Guarantee:** Bypass preloader, curtain wipe, cipher scrambles, block mask, and scroll-scrubbing immediately when `prefers-reduced-motion: reduce` is enabled, rendering full-contrast static states from first paint.

## Capabilities

### New Capabilities
- `landing-page-motion`: Public-site every-load preloader and upward curtain transition across all public pages (excluding `/admin` routes), plus homepage-specific synchronized hero entrance choreography, location scramble micro-interaction, live `hh:mm A (GMT +7)` hero clock, translucent borderless navbar with sharp inverted `BLOG` button, sticky hero overlap with `ScrollTrigger` word-by-word statement illumination, and `prefers-reduced-motion` fallbacks integrated with Azis's dual-theme (`Light`/`Dark`) and bilingual (`EN`/`ID`) CMS architecture.

### Modified Capabilities
- `design-system-theming`: Remove Header/Footer divider borders and `LocaleToggle`/`ThemeToggle` box borders (`EN / ID` slash toggle), add `Playfair Display` `700` and italic `400` weights plus `Plus Jakarta Sans` `500`/`700` usage (`LET'S HAVE` italic serif + `A CHAT` bold sans-serif), upgrade primary CTA directional arrow from `&rarr;` text glyph to inline SVG, refactor Footer layout/typography/scale (`© 2026 — AZIS MUHAMAD FADLI` explicit owner override + `hh:mm A (GMT +7)` + massive `azis` wordmark + bottom-right `LINKEDIN`, `GITHUB`, `INSTAGRAM`, `THREADS`), and remove `CMS` and `BASED IN INDONESIA` from Footer.
- `public-portfolio`: Remove Hero bottom/footer divider lines and vertical clock separator, center a uniform `2px` circle across a full-viewport section with dead-center `Plus Jakarta Sans` quote typography, mandate 1:1 official brand SVGs in `MOST FAVORITE TECH`, and update `ContactBanner.astro` with mixed italic-serif/bold-sans headline styling, crisp inline SVG CTA arrow, and rightward-expanding pill hover animation.
